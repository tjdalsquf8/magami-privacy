Android 앱 "마감이" (com.magami.app) · 시행일: 2026년 7월 27일

마감이는 계정을 유지한 상태에서 앱 내 데이터만 초기화할 수 있는 기능을 제공합니다. 아래 절차에 따라 언제든지 요청하실 수 있습니다.

방법 1. 앱 내에서 직접 초기화 (권장)

앱에서 전체 데이터 초기화하기

  1. 마감이 앱 실행
  2. 하단 탭에서 설정 진입
  3. 데이터 > 전체 데이터 초기화 메뉴 선택
  4. 안내 문구 확인 후 초기화 버튼 탭

초기화 즉시 아래에 명시된 모든 데이터가 서버에서 삭제되며, 계정은 그대로 유지됩니다.
